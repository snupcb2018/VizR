VizR - RNA-Seq Analysis Platform
===================================

Usage:
1. Double-click VizR.exe to launch.
2. Select data folder (Default: C:\Users\USERNAME\VizR_Data)
3. VizR will start automatically and open your web browser.
4. Access VizR at http://localhost:5001 in your browser.

Requirements:
- Docker Desktop (https://www.docker.com/products/docker-desktop)
- Internet connection (for initial image download)

Recommended Docker Desktop Settings:
- Open Docker Desktop Settings > General
- Uncheck "Open Docker Dashboard when Docker Desktop starts"
  (This prevents the Docker Dashboard window from opening automatically)

How to Stop VizR:
- Open Docker Desktop and stop the "vizr" container.

Troubleshooting:
- Verify Docker Desktop is running.
- Check if port 5001 is not blocked by firewall.
- View logs in Docker Desktop container logs.
